# 069: Timer calendar

Status: done

Each user can see their own time as a week calendar, and add and change entries in it, the
way a clinic's booking calendar works. It's a view of the Timer page next to the entry list,
not a new page. Design it in `prototypes/calendar.html` first.

## Acceptance criteria

- [x] Prototype: a List | Calendar switch on the Timer page, saved per user
- [x] Prototype: a work week with the weekend a toggle away, shown anyway when it has time
- [x] Prototype: drag or click to add, drag to move, drag an edge to change a time, click to
      edit, and Undo after each change
- [x] Prototype: Alt+arrows move a focused entry, with Shift changing its end
- [x] Prototype reviewed, and the open questions in `prototypes/README.md` decided
- [x] App: the Calendar view on the Timer page, with the list's validation and mutations
